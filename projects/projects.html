01

PROYEK AKHIR

AUTECAL

SUHU · INSTRUMENTASI

GAMBARAN PROYEK

AUTECAL merupakan sistem kalibrator suhu dry-well yang menggunakan sistem pendinginan aktif berbasis dua modul Peltier. Sistem dirancang untuk membantu proses kalibrasi sensor suhu dengan pengendalian temperatur berbasis PID.

KONTRIBUSI SAYA

  • Merancang sistem pendinginan aktif menggunakan dua modul Peltier.
  • Mengintegrasikan sensor PT100 dan MAX31865 untuk pengukuran temperatur.
  • Mengimplementasikan kontrol PID serta sistem monitoring melalui dashboard AUTECAL berbasis Firebase.

TEKNOLOGI

ESP32 PT100 MAX31865 Peltier PID QuickPID Firebase

DOKUMENTASI

HASIL

24.01°C Temperatur minimum
24.94 min Waktu mencapai rentang penerimaan 25°C
25.13°C Rata-rata temperatur

PROYEK MBKM

Flood Monitoring

IOT · MONITORING DATA

GAMBARAN PROYEK

Dashboard monitoring banjir berbasis web yang digunakan untuk menampilkan kondisi sungai secara berkelanjutan melalui data ketinggian air, curah hujan, data historis, prediksi, lokasi, dan indikator kondisi.

KONTRIBUSI SAYA

  • Mengembangkan visualisasi dashboard monitoring berbasis HTML, CSS, dan JavaScript.
  • Mengembangkan antarmuka untuk menampilkan ketinggian air, curah hujan, data historis, prediksi, dan indikator kondisi.
  • Mendukung pengumpulan dan persiapan data ketinggian air dan curah hujan untuk pengujian model machine learning.

TEKNOLOGI

HTML CSS JavaScript Data Visualization IoT Monitoring

DOKUMENTASI

OUTPUT

Dashboard monitoring banjir berbasis web dan visualisasi sistem peringatan dini untuk membantu penyajian informasi kondisi air secara lebih jelas.

03

PROYEK PLN

Smart Door Lock

IOT · KONTROL AKSES

GAMBARAN PROYEK

Prototipe sistem akses pintar untuk panel LBS dan Recloser menggunakan ESP32 dengan dua metode autentikasi, yaitu RFID dan Bluetooth.

KONTRIBUSI SAYA

  • Mengembangkan sistem autentikasi RFID menggunakan ESP32 dan PN532.
  • Mengembangkan kontrol door lock melalui koneksi Bluetooth menggunakan ESP32.
  • Pengembangan Aplikasi Flutter Membuat aplikasi mobile menggunakan Flutter untuk mengontrol pembukaan dan penutupan door lock melalui Bluetooth.
  • Mengintegrasikan ESP32, relay, dan solenoid lock sebagai sistem kontrol akses.
  • Merancang housing perangkat menggunakan Fusion 360.

TEKNOLOGI

ESP32 RFID PN532 Bluetooth Flutter Arduino IDE Relay Solenoid Lock Fusion 360

DOKUMENTASI

OUTPUT

Prototipe Smart Door Lock yang dapat dikendalikan menggunakan RFID maupun aplikasi mobile Flutter melalui koneksi Bluetooth.
